# AI-Powered Email Automation System

This project is an **AI-driven email automation platform** that integrates lead management, data enrichment, and intelligent outreach workflows.  

---

## 🚀 Features

### ✅ Current Functionality
- **Google Sheets Integration**  
  - Retrieve lead data directly from Google Sheets.  
  - Save enriched lead data back into the same row with new columns.  

- **Data Enrichment**  
  - Custom **web scraper** to collect client website data.  
  - **API-based LinkedIn scraper** to fetch client profile/company data.  

- **Email Campaign Management**  
  - Integrated with **[Instantly.ai API](https://instantly.ai/)**.  
  - Add campaigns, leads, and send personalized emails.  

---

### 🔜 Coming Soon
- **Email Tracking & State Management**  
  - Update Google Sheets with email send status, open/click events, and response tracking.  

- **Webhook Server**  
  - Receive email events (opens, clicks, replies) in real-time from Instantly.ai.  

- **RAG-Powered Reply Generation**  
  - Retrieval-Augmented Generation (RAG) for generating contextual email replies.  

- **Telegram Team Notifier**  
  - Notify marketing teams via Telegram to confirm or modify AI-generated replies before sending.  

---

### 🌱 Future Plans
- Advanced analytics dashboard for campaign performance.  
- AI-driven lead scoring and prioritization.  

---

## 🛠️ Tech Stack
- **Data Management**: Google Sheets API  
- **Scraping**: Custom Python scrapers + LinkedIn API-based scraper  
- **Email Automation**: Instantly.ai API  
- **AI**: RAG-based response generation  
- **Notifications**: Telegram Bot API  
- **Backend**: Webhook server (Flask/FastAPI planned)
